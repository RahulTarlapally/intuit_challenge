# Producer-Consumer with thread synchronization

A clean implementation of the producer-consumer pattern using 

    - Python Threads
    - Condition Variables
    - Blocking Queue Behavior
    - Proper Project Structure
    - Unit Tests

## Run the program

python src/main.py

## Run unit tests

python tests/

## Project structure

    producer_consumer
    |--- src/
    |    |--- config.py
    |    |--- producer.py
    |    |--- consumer.py
    |    |--- shared_queue.py
    |    |--- main.py
    |
    |--- tests/
    |    |
    |    --- test_producer_consumer.py
    |
    |--- requirements.txt

## Purpose

This assignment demonstrates

    - Thread synchronization (Condition)

    - Blocking behaviour (wait/notify)

    - Producer-consumer communication

    - Unit testing
